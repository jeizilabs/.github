# Jeizilabs

A small lab in Switzerland building software for neuroimaging, science and data. We are just
getting started.

**[Tractus](https://jeizilabs.com/tractus/)**: a lightweight replacement for 3D Slicer's daily workflows, built in Rust. Milestone M1 is in progress; there is no public release yet, and development builds for Linux, Windows and macOS go to testers.

**Consulting** in three areas:

- Neuroimaging and medical image analysis: MRI and EEG, tractography pipelines
- Scientific software engineering: Rust and Python tools, performance, visualisation, and turning
  research code into software people can rely on
- Data, ML and AI integration
